# Panduan Konten dan Pedagogi Python SMA

1. Gunakan tema cerita membantu pengelolaan usaha pengolahan hasil panen desa untuk Misi 1 pendataan modal dan omzet, Misi 2 perhitungan laba bersih, dan Misi 3 penentuan kelayakan ekspansi usaha.
2. Pastikan setiap soal hanya membutuhkan variabel, `int(input())`, operator aritmatika `-` dan `*`, percabangan `if-elif-else`, serta `print()`.
3. Petakan pesan kesalahan bawaan Python ke petunjuk bahasa Indonesia yang jelas:
   - `SyntaxError`: Periksa tanda titik dua di akhir baris `if/elif/else`, tanda kurung, atau spasi menjorok ke dalam.
   - `NameError`: Pastikan nama variabel sama persis dengan yang disebutkan oleh Konsultan Bisnis.
   - `ValueError`: Pastikan masukan dari pengguna sudah diubah menjadi angka bulat menggunakan `int()`.
